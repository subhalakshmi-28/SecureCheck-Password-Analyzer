
# SecureCheck - Password Strength Analyzer

## About
SecureCheck is a web-based Password Strength Analyzer
that evaluates password security and helps users
create stronger passwords.

## Features
- Real-time password strength analysis
- Password length validation
- Uppercase and lowercase validation
- Number and special character validation
- Repeated pattern detection
- Weak, Moderate, Strong and Very Strong ratings
- Secure random password generator
- Copy password functionality
- Password visibility toggle
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Web Crypto API

## Installation
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

## Privacy
Passwords are processed locally in the browser.
No password is uploaded to a server or stored
in a database.

## Limitations
This project does not check password reuse across
accounts or compare passwords against external
data breach databases. Repeated-pattern detection
is a basic local heuristic.
