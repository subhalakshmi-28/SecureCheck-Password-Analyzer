## 📌 Project Overview

SecureCheck is a web-based Password Strength Analyzer designed to improve password security awareness. It analyzes user-entered passwords based on multiple security requirements and provides instant feedback with personalized suggestions.

The application also includes a secure random password generator to help users create strong passwords.

## ✨ Features

- Real-Time Password Strength Analysis
- Password Length Validation
- Uppercase and Lowercase Letter Validation
- Number and Special Character Validation
- Repeated Pattern Detection
- Weak, Moderate, Strong and Very Strong Classification
- Password Score out of 100
- Show and Hide Password
- Secure Random Password Generator
- Copy to Clipboard Functionality
- Responsive Design

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website Structure |
| CSS3 | Styling and Responsive Design |
| JavaScript | Functionality and Validation |
| Web Crypto API | Secure Random Password Generation |

## 📂 Project Structure

```text
SecureCheck-Password-Analyzer/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Enter a password to analyze its strength.
5. Use the password generator to create a strong password.

## 🔒 Security and Privacy

- Password analysis happens locally in the browser.
- Passwords are not uploaded to an external server.
- Passwords are not stored in a database.
- Random password generation uses the Web Crypto API.

## ⚠️ Limitations

- Does not check password reuse across accounts.
- Does not connect to a database.
- Does not check passwords against known data breaches.
- Strength scores use basic heuristic rules.

## 🎯 Project Objective

To demonstrate password security concepts, client-side validation, JavaScript event handling, and secure random password generation.
